# Completed ticket archive

This directory preserves reviewed, marker-free execution records for completed
AIDD tickets. It is historical evidence, not the current source of product,
architecture, security, testing, operations, or workflow truth.

Use `docs/project/` for current durable decisions and
`docs/project/roadmap.md` for lifecycle status. Paths inside archived artifacts
describe their original active-workspace location and are intentionally not
rewritten.

No archive may contain `.active_ticket`, credentials, private keys, personal
email, raw SQL dumps, or private response bodies. A material correction or
redaction requires a normal reviewed documentation pull request.

Future completed tickets are added here by the same primary pull request that
